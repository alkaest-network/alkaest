# Security Policy

## Supported versions

This repository is an early-stage specification and planning project with no released protocol implementation. Security reports about the current default branch are welcome. Component implementations are maintained in separate repositories; report implementation vulnerabilities in the affected repository.

## Reporting a vulnerability

Please do not publish exploit details in a public issue or pull request. Use GitHub's [private vulnerability reporting form](https://github.com/alkaest-network/alkaest/security/advisories/new) if it is available for this repository.

If the private form is unavailable, open a minimal public issue titled **Request private security contact** without describing the vulnerability, affected systems, or reproduction steps. A maintainer can then provide a private channel. You may include the affected component, impact, and reproduction details once a private channel is established.

There is no guaranteed response time. Please allow maintainers time to investigate and coordinate a fix before public disclosure. Do not access, alter, or retain data that is not yours while investigating.
